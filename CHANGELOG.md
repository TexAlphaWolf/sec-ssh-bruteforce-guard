# Changelog

## 1.0.0

First release: sshd log parsing (syslog, ISO, journald JSON), weighted detector with fast, slow and user-spraying rules, per-user forgiveness, IPv6 /64 grouping, ban book with recidive and persistent state, nftables backend with per-element timeouts (plus dry-run and command backends), webhook and Telegram alerts, Prometheus textfile metrics, `scan` / `list` / `ban` / `unban` / `check-config`, Docker image, hardened systemd unit, simulator and scorer.
