# Security policy

If you find a vulnerability (for example a log line that makes the guard ban the wrong address, a way to reach a shell or the firewall with crafted input, or a crash from a crafted log), please use GitHub's **private vulnerability reporting** (Security tab, "Report a vulnerability") instead of a public issue. You will get an answer within a few days.

Supported: the latest release.

How the project defends itself is in [docs/security.md](docs/security.md).
